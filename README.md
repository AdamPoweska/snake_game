Classic Snake Game developed using Python and Pygame, showcasing core game development principles, including real-time gameplay, game loops, event handling, grid-based movement, collision detection, and basic AI-like logic for object interaction. The project features a dynamic gaming experience where players control a growing snake, collect randomly generated food items, and navigate challenges by avoiding collisions with walls and the snake's own body. Score tracking is implemented to enhance player engagement.
Responsibilities:
• Developed a fully functional Snake game using the Pygame library.  
• Implemented a real-time game loop to handle user input, rendering, and game state updates.  
• Designed grid-based movement logic enabling snake navigation in four directions.  
• Built a collision detection system for wall boundaries, self-collision, and food consumption events.  
• Implemented a dynamic snake growth mechanic triggered by food collection.  
• Created a random food spawning system using Python’s random module.  
• Developed a scoring system with real-time UI rendering using Pygame fonts.  
• Built a game over screen with restart/exit handling and visual feedback.  
• Managed frame rate control using Pygame clock to ensure consistent gameplay speed.  
• Handled keyboard input for both arrow keys and WASD controls.  
• Structured the core gameplay loop, including rendering, updates, and event processing.
